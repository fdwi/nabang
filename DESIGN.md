# DwiSave design direction

Reading this as: personal-finance web app for one account owner, in a warm personal-finance journal visual language, dial ENERGY 1 / RHYTHM 2 / MOTION 1.

- Palette: warm pink-salmon surfaces make DwiSave feel personal and distinct from generic banking dashboards; a deep rose accent is reserved for the logo, primary actions, and focus cues so financial values remain readable.
- Typography: the system sans-serif stack is used for dense numeric and form-heavy screens because it renders quickly and remains legible at small sizes; no display type is needed for this utility-first application.
- Layout: desktop navigation is a stable sidebar for frequent financial tasks; mobile prioritizes the dashboard and transaction route in a compact bottom navigation, with reserved bottom spacing.
- Surfaces: flat panels with restrained borders make data groupings clear without making every element appear elevated; the sole elevated control is the floating mobile transaction action to keep the primary task reachable.
- Logo: the D monogram uses an inner savings arc to connect the product name to a personal saving habit without relying on a separate decorative image asset.
- Icons: Lucide icons map directly to destinations such as wallet, receipt, and target; they supplement visible text rather than replace it.
- Motion: only short state transitions and focus feedback are allowed because financial entries demand attention, not decoration.
